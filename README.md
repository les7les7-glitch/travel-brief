# 여행 브리핑

항공·호텔 프로그램의 프로모션, 퍼스트·비즈니스 새 좌석, 럭셔리 호텔 소식을 골라 한국어로 요약하고, 오늘의 럭셔리 호텔과 오늘의 여행지, 취향·예산·좋았던 여행지로 찾는 여행지, 여행지별 2일 코스·식당·입국 준비, 축제가 담긴 여행 달력을 보여주는 페이지예요. GitHub Pages로 공개돼 있고, Claude가 매일 아침 데이터를 갱신해요.

## 구성

- `index.html`: 페이지 전체(HTML·CSS·JS 한 파일). `data/` 폴더의 JSON을 읽어 그려요.
- `data/items.json`: 프로모션·항공·호텔 소식
- `data/pick.json`: 오늘의 여행지와 지난 추천
- `data/budget.json`: 여행지별 예상 비용(만원 단위)과 느낌 점수. 예산으로 찾기와 느낌으로 찾기가 함께 써요.
- `data/digest.json`: 갱신 시각과 오늘의 한 줄 요약
- `data/guide.json`: 여행지 가이드. 2일 코스, 식당, 호텔 근처 볼거리를 한 줄씩 담아요(kind: hotel·day·stop·eat·near)
- `data/hotels.json`: 오늘의 럭셔리 호텔과 월드 베스트 호텔 목록. ‘월드 50 베스트 호텔’(51~100위 포함) 순위에 오른 객실 50실 이상 호텔이에요. 사진은 그 호텔을 찍은 Unsplash(무료 라이선스)나 위키미디어 공용(CC) 사진만 써요.
- `data/events.json`: 여행 달력의 축제·행사. 날짜가 아직 발표되지 않은 행사는 `start`·`end`를 비우고 `approx: true`, 대표 달은 `ym`(YYYY-MM)에 적어요.
- `data/entry.json`: 나라별 입국 준비(비자, 사전 허가, 입국 신고, 여권, 전압, 시차용 시간대, 돈, 팁, 여행경보). 한국 일반 여권·관광 기준이에요.
- `data/places.json`: 좋았던 여행지로 찾기에서 고를 수 있는 참고 여행지(우리 여행지 21곳 밖의 유명한 곳)와 성격 점수
- `scripts/export_public.py`: 비공개 대시보드 데이터에서 공개용 사본을 만드는 스크립트. 개인 일정 관련 소식과 문장은 빼고 내보내요.
- `manifest.webmanifest`, `icons/`: 휴대폰 홈 화면에 추가했을 때 앱처럼 열리게 하는 설정

## 화면 구성

- 홈: 대표 이미지와 ‘내 여행 찾기’, 마감 알림, 오늘의 럭셔리 호텔, 오늘의 여행지, 여행 찾기(취향·예산·좋았던 곳 탭), 여행 달력 미리 보기, 여행지 가이드·프로모션·항공·호텔 소식을 3개씩 보여주고 ‘전체 보기’로 이어져요.
- 주소 끝으로 화면을 바로 열 수 있어요: `#explore`(여행 찾기 결과), `#liked`(좋았던 곳으로 찾기), `#guide-<여행지 id>`(여행지 가이드와 입국 준비), `#calendar`(여행 달력), `#hotel`(오늘의 호텔·월드 베스트 호텔·호텔 소식), `#award`(마일리지 좌석 찾기), `#promo`·`#air`(소식 전체).
- 오늘의 럭셔리 호텔은 `hotels.json`에서 사진이 있는 호텔을 파일 순서대로 하루 한 곳씩 돌려요. 한국 날짜 기준이고, 2026년 10월 18일에 맨 앞 호텔에서 시작해요.
- 여행 달력은 지금 달부터 12달을 보여줘요. 달마다 `budget.json`의 `seasonMonths`로 가기 좋은 여행지를, `events.json`으로 그 달의 축제·행사를 모아요. 지난 행사는 저절로 빠져요.
- 여행지 카드는 사진·여행지·한 줄 소개·호텔·조건·예상 총액·상세보기 순서로 같고, 개장 연도·객실 수·소개·비용 그래프와 산식·가격 근거는 상세 화면에 있어요.
- 색, 글자 크기, 간격, 모서리 값은 `index.html` 맨 위 CSS 변수(`:root`)에 모여 있어요. 글꼴은 Pretendard예요.

## 취향으로 찾기 (느낌으로 찾기)

동행(혼자·연인·친구·가족), 느낌(바다에서 쉬기·화려한 호텔·도시 야경·쇼핑·미식·자연·풍경·문화·역사·활기·파티), 비행 거리를 고르거나 한 줄로 적으면 어울리는 3곳을 골라요.

- 여행지마다 느낌 점수(`vibeBeach`…`vibeNightlife`)와 동행 점수(`fitSolo`…`fitFamily`)를 0~100으로 매겨 두고, 고른 느낌의 가중 평균에 동행 점수(25%)를 섞어 순위를 매겨요.
- 고른 거리(`flightHours` 기준)보다 멀면 감점하고 카드에 표시해요. 글에 달이나 계절이 있으면 제철 여부도 따져요.
- 적은 글은 브라우저 안에서 낱말로만 읽어요(바다, 야경, 맛집, 부모님, 말고·싫어 같은 부정 표현 등). 어디로도 보내지 않아요.
- 느낌 점수는 여행지와 호텔 성격을 보고 Claude가 매긴 판단이에요.

## 좋았던 곳으로 찾기

다녀와서 좋았던 여행지를 고르면(우리 여행지 21곳과 `places.json`의 참고 여행지 중에서 검색), 성격 점수 일곱 가지(바다·호텔·도시·미식·자연·문화·활기)가 가장 닮은 우리 여행지를 보여줘요.

- 닮은 정도 = 100 − 1.2 × (두 곳 점수 차이의 제곱평균제곱근). 고른 곳마다 계산해 가장 높은 값을 카드에 ‘○○와 비슷 ○○%’로 적어요.
- 70% 넘는 곳을 보여주되 최소 3곳, 최대 9곳이에요. 우리 목록 밖의 비슷한 곳도 6곳까지 이름만 알려줘요.
- 고른 곳은 이 브라우저(localStorage `travel-brief-liked`)에만 저장되고 어디로도 보내지 않아요.

## 마일리지 좌석 찾기

항공 칸(홈에는 자주 쓰는 6곳, 항공 화면에는 17곳)에서 출발·도착 공항 코드와 날짜를 넣고 마일리지 프로그램을 누르면, 그 항공사 사이트가 새 창으로 열려요. 여행지 상세 화면의 ‘항공사별 마일리지 좌석’은 인천 출발 조건(고른 달 15일)을 채워 이 칸으로 데려와요.

- ‘조건 채워 열기’(알래스카 아트모스 리워즈, 아메리칸항공 에이어드밴티지, 유나이티드 마일리지플러스, 에어캐나다 에어로플랜)는 넣은 조건으로 바로 검색해요. 공항을 여러 개 넣으면 첫 번째 공항으로 열어요. 유나이티드는 로그인해야 마일리지 결과가 보여요.
- 나머지(대한항공, 아시아나, 델타, 플라잉블루, 버진애틀랜틱, 크리스플라이어, 영국항공, 카타르, 캐세이, JAL, 콴타스, 에미레이트, 에티하드)는 공식 마일리지 페이지(대한항공은 공식 ‘마일리지 예매’ 화면)를 열고, 로그인한 뒤 직접 검색해요.
- 이 사이트는 항공사 사이트를 대신 조회하거나 결과를 저장하지 않아요. 항공사 대부분이 자동 조회를 약관으로 막고 있어서, 누르면 내 브라우저에서 열리는 방식으로만 만들었어요.
- 현금가 비교는 구글 항공권으로 열고, 여러 프로그램을 한 번에 훑어볼 때 참고할 수 있게 seats.aero 링크도 둬요.
- 마지막으로 넣은 값은 이 브라우저(localStorage `travel-brief-award`)에만 저장돼요.

## 여행지 가이드

여행지 카드의 '가이드 보기'나 '여행지 가이드' 탭에서 열려요. 장소 이름은 구글 지도 검색으로, '길찾기'는 앞 장소에서 그 장소까지 길찾기로 열려요(API 키 없이 쓰는 Google Maps URL). 하루 동선 지도는 휴대폰 브라우저에서 경유지가 3곳까지만 되므로 하루 코스를 4곳으로 짜요. 식당은 미쉐린 가이드나 공식 사이트, 2025~2026년 기사에서 영업 중인지 확인한 곳만 넣고 출처를 달아요.

## 입국 준비

여행지 가이드(입국 준비 카드)와 상세 화면에 나와요. 시차는 `tz`(IANA 시간대)로 브라우저가 서머타임까지 반영해 지금 시각과 함께 계산해요. 각 나라 정부·대사관·외교부 해외안전여행 같은 공식 출처를 달았고, 조사한 날(`asOf`)을 함께 보여줘요.

## 갱신

```
python3 scripts/export_public.py <비공개 데이터 폴더> data
git add data && git commit -m "데이터 갱신" && git push
```

매일 아침 갱신은 `export_public.py`가 쓰는 파일(items·pick·budget·digest·guide)만 바꿔요. `hotels.json`, `events.json`, `entry.json`, `places.json`은 따로 조사해 손으로 고치는 파일이라 그대로 남아요.

가격과 조건은 조사한 날 기준 예상치예요. 입국 규정과 행사 날짜도 바뀔 수 있으니 예약 전에 각 카드의 출처에서 꼭 다시 확인하세요.
